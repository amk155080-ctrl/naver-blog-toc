우리동네보일러(우동보) v3.1 — 설치형 웹앱(PWA)
제작·작성: BC
========================================
이 파일은 APK가 아닙니다. PC·안드로이드·아이폰에서 홈 화면/앱 목록에 설치할 수 있는 웹앱입니다.

배포하기 (기존 GitHub Pages 저장소 사용)
1. 이 ZIP 압축을 풉니다.
2. GitHub에서 GitHub Pages가 켜진 저장소의 main 브랜치를 엽니다.
3. 저장소에 새 폴더 boiler-care 를 만들고 이 ZIP 안의 파일과 icons 폴더를 모두 업로드합니다.
   중요: boiler-care/index.html, boiler-care/manifest.webmanifest, boiler-care/sw.js, boiler-care/icons/*.png 위치가 유지되어야 합니다.
4. Pages 설정이 main / (root)라면 아래와 같은 형식의 주소로 접속합니다.
   https://<GitHub-사용자명>.github.io/<저장소명>/boiler-care/
   GitHub Pages가 이미 배포 중인 저장소에서도 각 파일이 게시되어야 설치됩니다.
5. 안드로이드: Chrome으로 위 주소 열기 → [앱 설치] 또는 Chrome ⋮ → [홈 화면에 추가]/[앱 설치].
6. 아이폰: Safari로 위 주소 열기 → 공유 → [홈 화면에 추가].
7. PC: Chrome/Edge로 주소 열기 → 주소창 앱 설치 아이콘 또는 메뉴의 [앱 설치].

동작·주의
- 지역 카테고리, 기존 내 업체 저장, 지도 이동, 공식 A/S, 견적 비교 기능을 유지했습니다.
- 웹앱 화면은 캐시에 저장해 인터넷이 끊겨도 다시 열 수 있으나, 외부 주소 목록/실시간 지도/업체 정보 업데이트는 인터넷이 필요합니다.
- 별도로 등록한 개인 수리점과 견적은 단말의 브라우저 저장 공간에만 보관됩니다. 이전 HTML 파일에서 등록한 데이터는 새 도메인에 자동으로 옮겨지지 않습니다.
- 업체 기록은 공개 지도정보를 바탕으로 한 초기 목록입니다. 영업 상태·수리 자격·전화번호·수리 가능 범위를 보증하지 않습니다.
- 새 동네 수리점을 전국에서 앱 안에 직접 자동 표시하려면 지도 API의 합법적 제공 범위와 키/도메인 설정이 필요합니다.
- 서비스 워커와 설치 지원은 https 도메인(또는 로컬 개발 localhost)이 있어야 동작합니다. file:// 방식으로 열면 설치되지 않습니다.
- 공개 배포 시 앱 이름/서비스 운영자의 개인정보 처리방침 및 상호 정보 적법성 등은 별도 점검해 주세요.

표시명 안내: 앱 전체 이름은 우리동네보일러, 홈 화면의 짧은 이름은 우동보, 제작·작성자 표기는 BC입니다.
게시된 기존 PWA에서 이름이 바로 바뀌지 않으면 Chrome의 설치 앱을 제거한 뒤 다시 설치해 주세요. 개인 수리점/견적 데이터는 해당 브라우저에 저장되므로 앱 삭제 전에 유의하세요.
